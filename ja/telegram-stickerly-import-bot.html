Sticker.ly のスタンプパックをインポートする Telegram Bot

著者: Sasha Kuznetsov
2023-04-05

アニメーション付き Sticker.ly パックを簡単に Telegram へインポート

Sticker.ly は Android および iPhone 向けの人気スタンプパック作成・管理アプリで、Google Play ストアだけでも1億ダウンロードを超えています。iMessage、WhatsApp、Telegram へのスタンプパックのインポートに対応していますが、アニメーションスタンプパックのインポート機能は WhatsApp のみに限定されています。

熱心な Telegram ユーザーであり布教者でもある私は、やり取りのために友人たちによく Telegram への移行を勧めています。しかし友人の多くは、WhatsApp など他プラットフォームにある豊富なスタンプライブラリが使えないことに不満を感じていました。私はそれを解決すると約束し、ついにやり遂げました。ご紹介します：Sticker.ly Sticker Pack Import Bot です。

使い方は簡単で、https://sticker.ly/s/HBBCR8 のような Sticker.ly のパック URL を送るだけです。すると Bot がスタンプを Telegram 対応のアニメーション形式に変換し、アニメーションスタンプパックをライブラリに追加するためのリンクを返してくれます。

なお、この Bot は静止画スタンプパックのインポートにも対応していますが、静止画パックについては Sticker.ly と Telegram が標準でインポートに対応しているため、そちらを使うことをおすすめします。

現在この Bot はベータ版のため、まれに失敗することがあります。スタンプパックの作成時に問題が発生した場合はもう一度試し、必要に応じて Bot 内の案内に従って途中まで作成されたスタンプパックを削除してください。
