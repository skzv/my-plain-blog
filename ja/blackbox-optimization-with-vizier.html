あらゆる種類のシステムを自動的かつインテリジェントに最適化する

機械学習モデルや何らかのアルゴリズム的システムを構築するとき、システムのアーキテクチャについてさまざまな選択を迫られます。たとえば機械学習アプリケーションなら、ニューラルネットワークの層にニューロンをいくつ配置するか、あるいは勾配降下法の学習率をいくつにするかを決めなければなりません。ロボットの状態を追跡するパーティクルフィルタを作っているなら、尤度関数の形状を選ぶ必要があるでしょう。あるいは、計算リソースの消費を最小化するバッファサイズとスレッド数を探しているかもしれません。こうしたシステムの最適なアーキテクチャはどうすれば見つけられるでしょうか？

手作業で探すこともできます。ニューロン数をいくつか変えてみたり、勾配降下法の学習率をいろいろ試したりするわけです。しかしこの作業は遅くて退屈なうえ、落とし穴にはまりやすいものです。ありがたいことに、システムを賢く効率的に最適化してくれるサービスが存在します。

Vizier の紹介

Vizier は、ブラックボックス最適化およびハイパーパラメータ最適化のために Google で開発された最適化サービスです。Vizier が提案する入力をシステムに渡し、システムから出力（Vizier が最大化または最小化しようとする評価指標）を受け取ることさえできれば、どのような種類のシステムでも最適化できます。システム自体は「ブラックボックス」として扱われます。

ブラックボックス最適化では、入力を渡して出力を受け取れさえすれば、システム内部を理解する必要はありません。出典：Per Instance Algorithm Configuration for Continuous Black Box Optimization - Scientific Figure on ResearchGate. https://www.researchgate.net/figure/black-box-Optimization_fig1_322035981 [2023年2月23日参照]

勾配降下法のような非ブラックボックス最適化手法では、システムのパラメータと最小化・最大化したい指標との関係を理解している必要がありますが、Vizier のようなブラックボックス最適化システムではシステム内部に関する知見が一切不要です。それでもパラメータ空間を効率よく探索し、システムを最適化するパラメータ値を見つけ出してくれます。この性質により、複雑で不連続、あるいは非凸な評価関数に対しても高い頑健性を発揮します。

パラメータとハイパーパラメータの違い

余談ですが、この区別は機械学習の分野に由来します。「パラメータ」はデータセットでの学習を通じて見つけられ、推論時にモデル内部で使われる値を指すのに対し、「ハイパーパラメータ」はモデルのアーキテクチャや学習手順を規定する値を指します。Vizier のようなブラックボックス最適化サービスはあらゆるシステムの最適化に使えますが、機械学習モデルそのものの学習に使うのは効率的ではありません。一方で、モデルのアーキテクチャを最適化するには非常に優れた手段です。

この信号にフィットする解析関数を見つけてみましょう。ガウス分布（正規分布）とラプラス分布のどちらを当てはめるべきか決めかねており、さらにどちらの関数にも平均や分散といった推定すべき固有のパラメータがあるとします。

問題のセットアップ

最初に探索対象としたいパラメータはモデルの種類、つまりガウス分布かラプラス分布かです。

{
    'parameter_id': 'model',
    'categorical_value_spec' : {
        'values': [
            'gaussian',
            'laplace',
        ]
}

しかし各モデルには、その形状を決める固有のパラメータセットがあります。これらを各モデルの「子パラメータ」と呼ぶことにしましょう。

ガウス分布の場合は、平均 mu (\(\mu\)) と標準偏差 sigma (\(\sigma\)) です。

パラメータ mu と sigma を持つガウス分布。出典：https://commons.wikimedia.org/wiki/File:Normal_Distribution_PDF.svg

ラプラス分布の場合は――文献によって記法は異なりますが――一般に、位置パラメータ（平均）mu (\(\mu\)) と尺度パラメータ b (\(b\)) があります。

パラメータ mu と b を持つラプラス分布。出典：https://commons.wikimedia.org/wiki/File:Laplace_pdf_mod.svg

ガウス分布の平均と区別するため、ここではラプラス分布の位置パラメータを mu ではなく a と呼ぶことにします。

ガウス分布を当てはめようとしているときに、Vizier にラプラス分布のパラメータまで推定してほしいとは思いませんし、逆もまた然りです。幸いなことに、各分布のパラメータは親パラメータ model に紐づく子パラメータ（条件付きパラメータ）として指定できます。

'conditional_parameter_specs': [
{
    "parameter_spec": {
        "parameter_id": "mu",
        "scale_type": 'UNIT_LINEAR_SCALE',
        "double_value_spec": {
        "min_value": 0,
        "max_value": 10.0,
        },
    },
    "parent_categorical_values": {
        "values": ['gaussian']
    }
},
{
    "parameter_spec": {
        "parameter_id": "sigma",
        "scale_type": 'UNIT_LINEAR_SCALE',
        "double_value_spec": {
        "min_value": 1e-1,
        "max_value": 5.0,
        },
    },
    "parent_categorical_values": {
        "values": ['gaussian']
    }
},
    {
    "parameter_spec": {
        "parameter_id": "a",
        "scale_type": 'UNIT_LINEAR_SCALE',
        "double_value_spec": {
        "min_value": 0,
        "max_value": 10.0,
        },
    },
    "parent_categorical_values": {
        "values": ['laplace']
    }
},
{
    "parameter_spec": {
        "parameter_id": "b",
        "scale_type": 'UNIT_LINEAR_SCALE',
        "double_value_spec": {
        "min_value": 1e-1,
        "max_value": 5.0,
        },
    },
    "parent_categorical_values": {
        "values": ['laplace']
    }
}]

最後に、Vizier が最適化する評価指標を定義します。関数を信号にできるだけ近づけたいので、解析関数とデータとの残差平方和（sum of squared residuals）を計算して当てはまりの良さを評価することにします。この値が小さいほど当てはまりが良いということです。Vizier に伝えるのは、この指標を最小化したいという点だけです。

metric_ssr = {
    'metric_id': 'sum_of_squared_residuals',
    'goal': 'MINIMIZE',
}

これらをすべてまとめると、問題の定義が完成します。

study = {
    'display_name': 'vizier_experiment',
    'study_spec' :
    {
        'parameters': [param_model],
        'metrics': [metric_ssr]
    }
}

なお、Vizier 自体はパラメータの意味をまったく理解していません。Gaussian も Laplace もカテゴリカルパラメータの値に過ぎず、Vizier にとってはそれ以上の意味を持たないのです。それらに意味を与えるのはパラメータを受け取る私自身のコードですが、Vizier から見ればそのコードはブラックボックスの中にあります。簡潔にするためここではコードを省略していますが、記事末尾のリンクから全容を確認できます。

探索

各トライアル（試行）で、Vizier は試すべきパラメータの組を提案してきます。私たちはそのパラメータがどれほどうまく機能するかを自前で評価し、指標（残差平方和）を計算して Vizier に返します。すると Vizier はその結果を使って、次に試すべきパラメータの組を生成します。

トライアルごとにパラメータを提案する Vizier。

モデルがガウス分布のときにはガウス分布のパラメータだけを、ラプラス分布のときにはラプラス分布のパラメータだけを提案している点に注目してください。

Vizier はどうやって最適なパラメータを探索しているのでしょうか？グリッドサーチやランダムサーチも選べますが、真価はガウス過程バンディット（Gaussian process bandits）や線形結合探索（linear combination search）、およびそれらの派生アルゴリズムの組み合わせにあります。
