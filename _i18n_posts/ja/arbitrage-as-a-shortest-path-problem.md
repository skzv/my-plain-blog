_お金を稼ぐのが嫌いな人などいるでしょうか？_

そしてもし、お金を稼ぐ問題を「最短経路を見つける問題」に変換できるとしたらどうでしょう？少なくとも一つの明確な方法があります。それが裁定機会（アービトラージの機会）を利用することです。

## 裁定取引（アービトラージ）とは？

_裁定取引（アービトラージ）_とは、異なる市場間や異なる形態の間で資産を売買し、価格差から利益を得る行為のことです。そしてこれを行う人々は_裁定取引者（アービトラージャー）_と呼ばれます。なかなか格好いい肩書きですね。

簡単な例から始めましょう。ポール、ピーター、ボブの3人が、ニンジン、ジャガイモ、レタスを物々交換している村に住んでいるとします。ボブはジャガイモとニンジンを、ピーターはレタスとジャガイモを、ポールはレタスとニンジンを交換しています。

さらに、ボブはニンジン1本に対してジャガイモ2個、ピーターはジャガイモ2個に対してレタス1玉、ポールはレタス1玉に対してニンジン2本で交換してくれるとします。それぞれの人物を各品物の「市場」と見なすと、交換レートは次のようになります。

| 市場                             | 交換レート                               |
|:--------------------------------:|:----------------------------------------:|
| ボブ（ジャガイモ／ニンジン）     | 2 ジャガイモ / ニンジン                  |
| ピーター（レタス／ジャガイモ）   | 1 レタス / 2 ジャガイモ = 0.5 レタス / ジャガイモ |
| ポール（ニンジン／レタス）       | 2 ニンジン / レタス                      |
{% include caption.html content="村における品物の交換レート。" %}

チャンスの気配を感じませんか？

商才あふれるあなたなら、これを活かそうとするはずです。まずニンジンを5本持ってボブのもとへ行き、彼の提示するレートでニンジン5本をジャガイモ10個に交換します。

{%include math.html content=
"
\begin{align}
5 \text{ carrots} \times 2 \space \frac{\text{potatoes}}{\text{carrots}} = 10 \text{ potatoes} \tag{1} \label{eq:arb_example}
\end{align}
" 
%}

次に、ジャガイモを持ってピーターのもとへ行くと、レタス5玉と交換してもらえます。そしてそのレタス5玉をポールのところへ持っていくと、ニンジン10本と交換してくれます。

わずか数回の賢い取引で、手持ちのニンジンを2倍に増やすことができました。裁定機会を突くことで、ニンジン5本を10本にしたのです。

やがて村が発展すると、ボブ、ピーター、ポールだけが取引相手ではなくなり、より洗練された市場が生まれます。この小さな村にもニンジン／レタス市場、レタス／ジャガイモ市場、ジャガイモ／ニンジン市場ができ、それぞれの取引レートは人々の売買意欲に応じて変動するようになるでしょう。

それでも裁定取引の原理は変わりません。そしてその機会は、そのレートで交換に応じる取引相手のニンジン、レタス、ジャガイモが尽きるまで利用され続けます。つまり、市場が均衡に達するまで裁定機会は消化されていくのです。

## 現代における裁定取引

現代の市場と聞いて、ニンジンやジャガイモ、レタスの取引を思い浮かべる人はあまりいないでしょう。外国為替（FX）に関心がある方なら、ドル、ポンド、円の取引を思い浮かべるはずです。その場合、ドル／ポンド市場、ポンド／円市場、円／ドル市場が存在し、各市場で多数のトレーダーが取引を行っています。ここからは取引対象の例としてこれらの通貨を使いますが、同じ原理はあらゆる取引可能な資産に当てはまることを念頭に置いてください。

ある時点で、為替レートが次のようになっているとします。

| 市場                   | 為替レート          |
|:----------------------:|:-------------------:|
| ポンド (£) / ドル ($)  | 0.8 ポンド / ドル   |
| 円 (¥) / ポンド (£)    | 100 円 / ポンド     |
| ドル ($) / 円 (¥)      | 0.013 ドル / 円     |
{% include caption.html content="通貨市場における為替レートの例。" %}

先ほどのボブ、ピーター、ポールによるニンジン・レタス・ジャガイモの取引から学んだ方なら、ここにもチャンスがあると気づくはずです。

1ドルをポンドに替えると£0.8になります。それを円に替えると¥80になります。その円を円／ドル市場で再びドルに替えると……なんと$1.04になっているのです！

ただし、他の裁定取引者に先を越されないよう、素早く行動しなければなりません。こうした機会は一時的にしか存在せず、流動性が使い切られてレートが均衡するまでの間だけです。

鋭い方なら、この例では取引手数料を考慮していないことにお気づきでしょう。実際に利益の出る裁定機会が存在するかどうかを計算するには、当然ながら手数料も織り込む必要があります。

## 素早く行動する

なぜスピードが何より重要なのか、直感的にご理解いただけたと思います。為替レートは目まぐるしく変動し、そのレートで取引できる「モノ」の量には限りがあるからです。

ここまで扱ったのは比較的シンプルな例ですが、実際の裁定機会は何段階もの取引にまたがり、非常に複雑になり得ます。先の例は3回の取引でしたが、10回の取引が必要だったらどうでしょう？さらに、20種類の通貨があり、すべてのペアに市場が存在するネットワークの中で、どれだけ速く機会を見つけられるでしょうか？

コンピュータを使うのが明らかな答えです。しかし、誰かに先を越されないためには、効率的なアルゴリズムが必要になります。

それを実現するために、数学とコンピュータサイエンスにおけるいくつかの巧みな発想を活用できます。

## グラフとしての市場

グラフは、数多くの応用分野で活用されている極めて重要なデータ構造です。社会構造や自然界の多くの仕組みがグラフでモデル化でき、実は市場もその一つです。

今回のケースでは、それぞれの通貨をノード（頂点）として扱います。あるノードから別のノードへの移動が、ある通貨を別の通貨に交換することに対応します。

![簡略化した通貨グラフ]({{ "/currency-graph-white.png" | prepend: page.imgpath }}){: width="448" height="283" loading="lazy" decoding="async"}
{% include caption.html content="簡略化したグラフ — 実際には各方向に個別のエッジ（有向辺）が必要です。" %}

したがって、ノード間を結ぶエッジ（辺）に沿って移動することは、保有通貨の金額に為替レートを掛ける操作に対応します。

つまり、ドルノードからポンドノードへの移動は、0.8ポンド／ドルを掛けることを意味します。各エッジの重みとして、この為替レートを割り当てましょう。

ここで注意すべき点として、双方向の為替レートは互いに_おおよそ_逆数の関係にあります。つまり、ドルからポンドへの換算レートが0.8ポンド／ドルであれば、逆方向のレートは 1 / (0.8ポンド／ドル) = 1.25ドル／ポンド程度になります。そのため、各市場での買いと売りは、それぞれ異なる重みを持つ別個の有向エッジとして扱う必要があります。

双方向の為替レートが完全にではなく_おおよそ_逆数にとどまる理由は、通貨を買う価格と売る価格の間にわずかな差、すなわちビッド・アスク・スプレッド（売値と買値の差）があるためです。たとえば、ある時点で0.8ポンド／ドルでポンドを買える（相手があなたに売ってくれる現在の価格）一方、ポンドを売ってドルに替えるときは0.82ポンド／ドル（つまり1.22ドル／ポンド、相手があなたから買ってくれる現在の価格）だとすると、グラフモデルは次のようになります（簡単のため他の為替レートは省略しています）。

![為替レート付きの通貨グラフ]({{ "/currency-graph-w-exchange-rates-white.png" | prepend: page.imgpath }}){: width="451" height="378" loading="lazy" decoding="async"}

一連の取引は、このグラフ上のエッジを辿ることでモデル化でき、取引の結果は移動したエッジの重みを**_掛け合わせる_**ことで計算されます。

## チャンスを見抜く

モデルができたところで、裁定機会に対応する構造はこのグラフの中でどのようなものになるでしょうか？

一連の取引で利益が出たかどうかを判断するには、一貫した評価基準が必要です。言い換えれば、ドルから取引を始めたなら、最後もドルで終える必要があります。そうして、最終的なドル額を最初のドル額と比べることで、利益が出たかどうかがわかるのです。

グラフ上で言えば、一連の取引は出発したのと同じノードに戻ってこなければなりません。今回の例では、ドルノードから出発してドルノードに戻ってきます。グラフ理論の用語では、これをサイクル（閉路）と呼びます。つまり探しているのは何らかのサイクルですが、利益が出るのはどのようなサイクルでしょうか？

サイクルのエッジに沿って重みを掛け合わせていくと、実効的な為替レートの単位が変換されていくことに注目してください。

{%include math.html content=
"
\begin{align}
a \space \frac{\cancel{£}}{$} \times b \space \frac{¥}{\cancel{£}} = ab \space \frac{¥}{$}  \tag{2} \label{eq:units_of_exchange_rate}
\end{align}
" 
%}

そして出発元のノードに戻ってきたとき、その量は無次元（単位なし）になります。為替レートから、リターン倍率へと変わるのです！グラフ上のサイクルを辿って途中の為替レートの積を計算することは、一連の取引を終えたあとに得られるリターン倍率を求めることに対応します。

{%include math.html content=
"
\begin{align}
a \space \frac{\cancel{£}}{\cancel{$}} \times b \space \frac{\cancel{¥}}{\cancel{£}} \times c \space \frac{\cancel{$}}{\cancel{¥}} = abc \space \text{[dimensionless]}  \tag{3} \label{eq:unitless_exchange}
\end{align}
" 
%}

市場が完全に効率的であれば、為替レートが均衡しているため、リターン倍率 $$abc$$ は1になります。重みの積が1より大きければ（たとえば1.02であれば）、この裁定機会によって2%の利益が得られたことになります。

したがって、任意の回数の取引へ一般化すると、裁定機会は次の不等式で表されます。

{%include math.html content=
"
\begin{align}
\prod_i^n{e_i} = e_ie_2...e_n > 1  \tag{4} \label{eq:arbitrage_return}
\end{align}
" 
%}

ここで $$e_i$$ は $$n$$ 回の取引における $$i$$ 番目の取引の為替レートを表します。

つまり私たちが必要としているのは、市場のグラフ上で「エッジの重みの積が1より大きいサイクル」を見つけ出すアルゴリズムです。自前でアルゴリズムを考案することもできるかもしれませんが、コンピュータサイエンスでは（人生全般でもそうですが）、目の前の問題を「すでに解き方を知っている問題」に帰着させるのが有効です。

## ベルマン・フォード法（Bellman-Ford Algorithm）

最短経路を見つける問題は、コンピュータサイエンスにおける定番かつ基礎的な問題であり、さまざまな場面に応用されています。グラフと地図を対応づけることで、地図上の最短ルートを求めるのが最もわかりやすい例でしょう。しかし少し工夫すれば、他にも多種多様な問題を最短経路問題へと変換できます。これからお見せするのは、裁定機会の発見もまさにそうした問題の一つだということです。

まず、最短経路問題とは何かを確認しましょう。グラフ内の2つのノード $$s$$ と $$t$$ が与えられたとき、最短経路とはエッジの重みの_和_を最小化する経路のことです。すなわち、$$s$$ から $$t$$ へ経路を辿りながらエッジの重みを足し合わせていったとき、その合計が最小になる経路（最小コストの経路）が最短経路です。

次に、最短経路問題にはいくつかの種類があることを押さえておきましょう。地図上の最短ルートのようなわかりやすい例では、エッジの重みは正でなければなりません。タイムマシンでもない限り、道路を走って移動時間が減ることはないからです。正の重みしか持たないグラフであれば、有名なダイクストラ法（Dijkstra's algorithm）によってグラフ内のすべてのノードへの最短経路を計算できます。

しかし、グラフが負の重みを持ってはいけない理由はありません。その場合、負の重みのエッジを通ると経路の総コストが減少します。ここで問題になるのが、重みの合計が負になる_サイクル_が存在する場合です。そのような_サイクル_を延々と回り続ければ、周回するたびに経路の総コストが下がり続け、最短経路のコストは $$-\infty$$ へと発散してしまいます。そのため、最短経路アルゴリズムには「負の重みのサイクル（負閉路）」を検出する仕組みがあると非常に便利です。そうでなければ、最短経路の探索は負閉路を永遠に回り続けることになってしまいます。

ベルマン・フォード法は、まさにそのためのアルゴリズムです。ダイクストラ法をより一般化したもので、負の重みを扱うことができます。その過程で、エッジの重みを_足し合わせる_と負の値になるサイクル、すなわち_負閉路（negative weight cycles）_を検出できるのです。

しかし、エッジの重みの**_積_**が1より大きいサイクルを見つけたいときに、エッジの重みの**_和_**が0より小さいサイクルを見つけるアルゴリズムがどう役に立つのでしょうか？

## 救世主としての対数（log）

次なるひらめきは、以下の対数の恒等式を使えば「積」を「和」に変換できるという点です。

{%include math.html content=
"
\begin{align}
\log{ab} = \log{a} + \log{b}  \tag{5} \label{eq:log_product_identity}
\end{align}
" 
%}

これによって、「_積_が1より大きいサイクルを見つける問題」を「_和_が0より大きいサイクルを見つける問題」へと変換できます！各為替レートの対数を取り、それをエッジの重みとして使えばよいのです。

先ほどの不等式の両辺に対数を取って確かめてみましょう。まず、左辺の対数を取ると、積の計算が和の計算に変わります。

{%include math.html content=
"
\begin{align}
\log{\prod_i^n{e_i}} = \log{e_ie_2...e_n} = \log{e_1} + ... + \log{e_n} = \sum_i^n{\log{e_i}} \tag{6} 
\end{align}
" 
%}

右辺の対数を取ると、1がちょうど0に変わります。

{%include math.html content=
"
\begin{align}
\sum_i^n{\log{e_i}} > \log{1} \rightarrow \sum_i^n{\log{e_i}} > 0 \tag{7}
\end{align}
" 
%}

もう一息です。既知のアルゴリズムで解ける形に帰着させる最後のステップは、各エッジの重みに -1 を掛けることです。これにより、正の重みのサイクルを探す問題が、負の重みのサイクルを探す問題へと変わります。

{%include math.html content=
"
\begin{align}
\sum_i^n{-\log{e_i}} < 0 \tag{8}
\end{align}
" 
%}

これこそ、ベルマン・フォード法が得意とする問題です！このようにグラフを構築してベルマン・フォード法を実行すれば、裁定機会を素早く効率的に見つけ出すことができます。裁定取引の問題を最短経路問題――いわば_無限に短い経路_を探す問題――へと変換できたからです。

![負の対数を重みにした通貨グラフ]({{ "/neg-log-currency-graph-white.png" | prepend: page.imgpath }}){: width="448" height="283" loading="lazy" decoding="async"}
{% include caption.html content="為替レートの負の対数をエッジの重みとして、負の重みのサイクル（負閉路）を探します。" %}

後から振り返ってみると、周回するたびに経路コストが減っていく負閉路と、周回するたびに利益が増える裁定機会が対応しているのは実に自然なことです。鍵となったのは、エッジの重みに $$-\log$$ を適用することで、積が1より大きいサイクルを探す問題を、和が0未満のサイクルを探す問題に変換した点にあります。

## 実際に確かめてみよう

先ほどの為替レートにこのアルゴリズムを適用し、裁定機会を正しく検出できるか見てみましょう。各為替レートを $$-\log$$ で変換すると、次のようになります。

| 市場                   | -log(為替レート) |
|:----------------------:|:----------------:|
| ポンド (£) / ドル ($)  | 0.223            |
| 円 (¥) / ポンド (£)    | -4.605           |
| ドル ($) / 円 (¥)      | 4.343            |

取引全体で合計すると不等式が成り立ちます――_負閉路が見つかりました_！

{%include math.html content=
"
\begin{align}
\sum_i^n{-\log{e_i}} = 0.223 - 4.605 + 4.343 = -0.039 \label{eq:neg_log_exchange_rate_example} \tag{9}
\end{align}
" 
%}

対数変換を元に戻せば積が復元され、リターンを計算できます。

{%include math.html content=
"
\begin{align}
\prod_i^n{e_i} &= \exp{\sum_i^n{-\log{e_i}}} \\
\prod_i^n{e_i} &= \exp(0.039) = 1.04 \tag{10}
\end{align}
" 
%}

これは先ほど計算した4%のリターンとぴったり一致します。

## 現実の世界では

裁定機会が負閉路に対応するなら、そのサイクルを永遠に回り続ければ無限にお金を稼げるように思えるかもしれません。もちろん、現実はそうはいきません。

どのような裁定機会であっても、流動性――価格が大きく動かずに取引できる数量――には限りがあり、コンピュータ技術や物理法則の限界に挑みながら互いに競い合うアルゴリズムトレーダーたちによって瞬く間に取り尽くされてしまいます。

とはいえ、グラフ理論とよく知られた最短経路アルゴリズムを金融分野の問題――そしてお金を稼ぐこと――に応用するこの思考実験を、私がいつも感じているのと同じくらい楽しんでいただけたなら幸いです。
