Когда вы создаёте модель машинного обучения — или любую другую алгоритмическую систему — вам приходится принимать решения об её архитектуре. Например, в задачах машинного обучения нужно выбрать количество нейронов в слое нейросети или скорость градиентного спуска. Если вы делаете [фильтр частиц](https://en.wikipedia.org/wiki/Particle_filter) для отслеживания состояния робота, нужно подобрать форму функции правдоподобия. Или, скажем, вы ищете размер буфера и число потоков, при которых система потребляет минимум вычислительных ресурсов. Как найти оптимальную конфигурацию?

Можно подбирать параметры вручную: пробовать разное число нейронов, менять скорость градиентного спуска. Но это медленно, утомительно и чревато ошибками. К счастью, существуют сервисы, которые умеют оптимизировать вашу систему за вас — умно и эффективно.

<div class="divider"></div>

## Знакомьтесь: Vizier

[Vizier](https://github.com/google/vizier) — это сервис оптимизации, созданный в Google для оптимизации чёрного ящика и подбора гиперпараметров. Его можно применять к любой системе, если вы способны передавать ей входные параметры (которые предлагает Vizier) и получать на выходе метрики, которые Vizier должен оптимизировать (максимизировать или минимизировать). Сама система при этом рассматривается как чёрный ящик.

![Оптимизация чёрного ящика]({{ "/black-box-optimization.png" | prepend: page.imgpath }}){: width="629" height="319" loading="lazy" decoding="async"}
{% include caption.html content="Оптимизация чёрного ящика не требует понимания внутреннего устройства системы — достаточно уметь передавать входы и получать выходы. Источник: Per Instance Algorithm Configuration for Continuous Black Box Optimization — научная иллюстрация на ResearchGate. Доступно по адресу: https://www.researchgate.net/figure/black-box-Optimization_fig1_322035981 [дата обращения: 23 февраля 2023]" %}

В отличие от методов оптимизации, опирающихся на внутреннее устройство функции, таких как [градиентный спуск](/ru/gradient-descent), которым нужно знать зависимость между параметрами системы и оптимизируемой метрикой, алгоритм чёрного ящика вроде Vizier вообще не требует знаний о самой системе. При этом он эффективно исследует пространство параметров и находит значения, оптимизирующие работу системы. Это также делает его более устойчивым к сложным, разрывным и невыпуклым целевым функциям.

<div class="divider"></div>

## Параметры и гиперпараметры

Небольшое отступление: само разделение пришло из машинного обучения, где «параметрами» называют внутренние значения модели, используемые при инференсе и подбираемые в ходе обучения на датасете, а «гиперпараметры» описывают архитектуру модели или саму процедуру обучения. Хотя сервис оптимизации чёрного ящика вроде Vizier способен оптимизировать любую систему, для непосредственного обучения весов нейросети он будет неэффективен. Зато для подбора архитектуры модели он подходит отлично.

## Пример

Я приведу пример, не связанный с машинным обучением, но хорошо демонстрирующий мощь и простоту алгоритма оптимизации чёрного ящика вроде Vizier. Представим, что у нас есть зашумлённый сигнал, как на графике ниже:

![Зашумлённый сигнал]({{ "/some-noisy-signal.png" | prepend: page.imgpath }}){: width="368" height="246" loading="lazy" decoding="async"}
{% include caption.html content="Некоторый зашумлённый сигнал." %}

Попробуем подобрать аналитическую функцию, описывающую этот сигнал. Мы не знаем заранее, что лучше подойдёт — [нормальное (гауссово) распределение](https://en.wikipedia.org/wiki/Normal_distribution) или [распределение Лапласа](https://en.wikipedia.org/wiki/Laplace_distribution), и у каждой из этих функций есть собственные параметры (такие как среднее и дисперсия), которые тоже нужно оценить.

Как только мы зададим для Vizier метрику оптимизации, он сам найдёт для нас оптимальную функцию.

<div class="divider"></div>

## Постановка задачи

Первый параметр, по которому мы хотим вести поиск, — это тип модели: гауссова или Лапласа:

```
{
    'parameter_id': 'model',
    'categorical_value_spec' : {
        'values': [
            'gaussian',
            'laplace',
        ]
}
```

Но у каждой модели есть свой набор параметров, определяющих её форму. Назовём их «дочерними параметрами» каждой модели.

Для распределения Гаусса это среднее `mu` ($$\mu$$) и стандартное отклонение `sigma` ($$\sigma$$).

![Распределение Гаусса с параметрами mu и sigma.]({{ "/normal-distribution.png" | prepend: page.imgpath }}){: width="720" height="460" loading="lazy" decoding="async"}
{% include caption.html content="Распределение Гаусса с параметрами mu и sigma. Источник: https://commons.wikimedia.org/wiki/File:Normal_Distribution_PDF.svg" %}

Для распределения Лапласа — обозначения зависят от литературы — обычно используют параметр сдвига (среднее) `mu` ($$\mu$$) и параметр масштаба `b` ($$b$$).

![Распределение Лапласа с параметрами mu и b.]({{ "/laplace-distribution.png" | prepend: page.imgpath }}){: width="800" height="600" loading="lazy" decoding="async"}
{% include caption.html content="Распределение Лапласа с параметрами mu и b. Источник: https://commons.wikimedia.org/wiki/File:Laplace_pdf_mod.svg" %}

Чтобы не путать его со средним распределения Гаусса, назовём параметр сдвига распределения Лапласа `a` вместо `mu`.

Когда мы подгоняем гауссову модель, нам не нужно, чтобы Vizier пытался оценивать параметры распределения Лапласа, и наоборот. К счастью, мы можем указать параметры каждого распределения как дочерние, или условные, параметры родительского параметра `model`:

```
'conditional_parameter_specs': [
{
    "parameter_spec": {
        "parameter_id": "mu",
        "scale_type": 'UNIT_LINEAR_SCALE',
        "double_value_spec": {
        "min_value": 0,
        "max_value": 10.0,
        },
    },
    "parent_categorical_values": {
        "values": ['gaussian']
    }
},
{
    "parameter_spec": {
        "parameter_id": "sigma",
        "scale_type": 'UNIT_LINEAR_SCALE',
        "double_value_spec": {
        "min_value": 1e-1,
        "max_value": 5.0,
        },
    },
    "parent_categorical_values": {
        "values": ['gaussian']
    }
},
    {
    "parameter_spec": {
        "parameter_id": "a",
        "scale_type": 'UNIT_LINEAR_SCALE',
        "double_value_spec": {
        "min_value": 0,
        "max_value": 10.0,
        },
    },
    "parent_categorical_values": {
        "values": ['laplace']
    }
},
{
    "parameter_spec": {
        "parameter_id": "b",
        "scale_type": 'UNIT_LINEAR_SCALE',
        "double_value_spec": {
        "min_value": 1e-1,
        "max_value": 5.0,
        },
    },
    "parent_categorical_values": {
        "values": ['laplace']
    }
}]
```

Наконец, нужно задать метрику, которую будет оптимизировать Vizier. Я хочу подобрать функцию как можно ближе к сигналу и буду оценивать качество подгонки по сумме квадратов остатков между аналитической функцией и данными. Чем меньше это число, тем лучше совпадение. Всё, что нужно сообщить Vizier, — что эту метрику следует минимизировать:

```
metric_ssr = {
    'metric_id': 'sum_of_squared_residuals',
    'goal': 'MINIMIZE',
}
```

Собираем всё вместе — и получаем описание задачи:

```
study = {
    'display_name': 'vizier_experiment',
    'study_spec' :
    {
        'parameters': [param_model],
        'metrics': [metric_ssr]
    }
}
```

Обратите внимание, что Vizier ничего не знает о смысле самих параметров. `Gaussian` и `Laplace` для него — просто значения категориального параметра, и никакого дополнительного значения они для него не имеют. Смысл им придаёт мой собственный код, который их использует, но для Vizier этот код находится внутри чёрного ящика. Я опускаю его ради краткости, но вы можете посмотреть весь код по ссылке в конце статьи.

## Поиск

На каждом испытании (trial) Vizier предлагает набор параметров для проверки. Мы сами оцениваем, насколько хорошо эти параметры работают, вычисляем метрику (сумму квадратов остатков) и возвращаем результат обратно в Vizier. На основе этого результата Vizier формирует следующий набор параметров.

![Vizier предлагает параметры для испытаний]({{ "/vizier-trials.png" | prepend: page.imgpath }}){: width="1280" height="281" loading="lazy" decoding="async"}
{% include caption.html content="Vizier предлагает параметры для испытаний." %}

Заметьте, что Vizier предлагает параметры Гаусса только тогда, когда выбрана модель `gaussian`, и аналогично для модели `laplace`.

Как именно Vizier ищет оптимальные параметры? Он умеет выполнять поиск по сетке или случайный поиск, но настоящая магия кроется в комбинации более продвинутых алгоритмов: бандитов на гауссовских процессах, поиска по линейным комбинациям и их вариаций.
