Otimize qualquer tipo de sistema de forma automática e inteligente

Quando você constrói um modelo de aprendizado de máquina — ou qualquer outro tipo de sistema algorítmico —, precisa tomar decisões sobre a arquitetura desse sistema. Por exemplo, em uma aplicação de machine learning, talvez precise decidir quantos neurônios colocar em uma camada de uma rede neural ou qual taxa usar no gradiente descendente. Ou, se estiver construindo um filtro de partículas para rastrear o estado de um robô, talvez precise escolher o formato de uma função de verossimilhança. Talvez você esteja procurando um tamanho de buffer e um número de threads que minimizem o uso de recursos computacionais. Como encontrar a arquitetura ideal para o seu sistema?

Você pode tentar encontrar manualmente. Pode testar diferentes quantidades de neurônios. Pode testar diferentes taxas de gradiente descendente. Mas esse processo é lento, tedioso e sujeito a armadilhas. Felizmente, existem serviços capazes de otimizar o seu sistema para você, de maneira inteligente e eficiente.

Apresentando o Vizier

O Vizier é um serviço de otimização criado no Google para otimização caixa-preta e ajuste de hiperparâmetros. Ele pode ser usado para otimizar qualquer tipo de sistema, desde que você consiga passar entradas sugeridas pelo Vizier para o sistema e obter saídas dele — métricas que o Vizier tentará otimizar, maximizando-as ou minimizando-as. O sistema em si é tratado como uma caixa-preta.

A otimização caixa-preta não exige nenhum entendimento interno do sistema, desde que seja possível fornecer entradas e obter saídas. Fonte: Per Instance Algorithm Configuration for Continuous Black Box Optimization - Scientific Figure on ResearchGate. Disponível em: https://www.researchgate.net/figure/black-box-Optimization_fig1_322035981 [acesso em 23 fev. 2023]

Diferentemente de métodos que não são caixa-preta, como o gradiente descendente, que exigem compreender a relação matemática entre os parâmetros do sistema e a métrica a ser minimizada ou maximizada, um sistema caixa-preta como o Vizier não precisa de nenhum conhecimento interno sobre o funcionamento do sistema. Ainda assim, ele consegue explorar o espaço de parâmetros de forma eficiente e encontrar os valores que otimizam o seu sistema. Isso também o torna mais robusto a funções de métricas complexas, descontínuas e não convexas.

Parâmetros vs. Hiperparâmetros

Um parêntese: essa distinção vem das aplicações de aprendizado de máquina, nas quais “parâmetros” são os valores internos do modelo usados na inferência e aprendidos durante o treinamento em um conjunto de dados, enquanto “hiperparâmetros” descrevem a arquitetura do modelo ou o procedimento de treinamento. Um serviço de otimização caixa-preta como o Vizier pode ser usado para otimizar qualquer tipo de sistema, mas não seria uma forma eficiente de treinar um modelo de aprendizado de máquina. Por outro lado, é uma excelente maneira de otimizar a arquitetura desse modelo.

Um exemplo

Vou usar um exemplo que não tem relação com aprendizado de máquina, mas que demonstra muito bem o poder e a simplicidade de um algoritmo de otimização caixa-preta como o Vizier. Digamos que temos um sinal ruidoso como o abaixo:

Um sinal ruidoso.

Vamos tentar encontrar uma função analítica que se ajuste a esse sinal. Não sabemos ainda se queremos ajustar uma função gaussiana ou de Laplace ao sinal, e ambas têm seus próprios parâmetros — como média e variância — que também precisamos estimar.

Desde que possamos fornecer ao Vizier uma métrica para otimizar, ele encontrará a função ótima para nós.

Configurando o problema

O primeiro parâmetro que queremos explorar é o tipo de modelo: gaussiano ou de Laplace:

{
    'parameter_id': 'model',
    'categorical_value_spec' : {
        'values': [
            'gaussian',
            'laplace',
        ]
}

Mas cada modelo tem seu próprio conjunto de parâmetros que define o seu formato. Vamos chamá-los de “parâmetros filhos” de cada modelo.

Para a distribuição gaussiana, esses parâmetros são a média mu (\(\mu\)) e o desvio padrão sigma (\(\sigma\)).

Distribuição gaussiana com parâmetros mu e sigma. Extraída de: https://commons.wikimedia.org/wiki/File:Normal_Distribution_PDF.svg

Para a distribuição de Laplace — a notação varia conforme a literatura —, geralmente temos o parâmetro de localização (ou média) mu (\(\mu\)) e o fator de escala b (\(b\)).

Distribuição de Laplace com parâmetros mu e b. Extraída de: https://commons.wikimedia.org/wiki/File:Laplace_pdf_mod.svg

Para evitar ambiguidade com a média da gaussiana, vamos chamar o parâmetro de localização da distribuição de Laplace de a em vez de mu.

Quando estivermos ajustando a distribuição gaussiana, não queremos que o Vizier tente estimar os parâmetros da distribuição de Laplace, e vice-versa. Felizmente, podemos especificar os parâmetros de cada distribuição como parâmetros filhos — ou condicionais — do parâmetro pai model:

'conditional_parameter_specs': [
{
    "parameter_spec": {
        "parameter_id": "mu",
        "scale_type": 'UNIT_LINEAR_SCALE',
        "double_value_spec": {
        "min_value": 0,
        "max_value": 10.0,
        },
    },
    "parent_categorical_values": {
        "values": ['gaussian']
    }
},
{
    "parameter_spec": {
        "parameter_id": "sigma",
        "scale_type": 'UNIT_LINEAR_SCALE',
        "double_value_spec": {
        "min_value": 1e-1,
        "max_value": 5.0,
        },
    },
    "parent_categorical_values": {
        "values": ['gaussian']
    }
},
    {
    "parameter_spec": {
        "parameter_id": "a",
        "scale_type": 'UNIT_LINEAR_SCALE',
        "double_value_spec": {
        "min_value": 0,
        "max_value": 10.0,
        },
    },
    "parent_categorical_values": {
        "values": ['laplace']
    }
},
{
    "parameter_spec": {
        "parameter_id": "b",
        "scale_type": 'UNIT_LINEAR_SCALE',
        "double_value_spec": {
        "min_value": 1e-1,
        "max_value": 5.0,
        },
    },
    "parent_categorical_values": {
        "values": ['laplace']
    }
}]

Por fim, precisamos definir a métrica que o Vizier vai otimizar. Quero ajustar uma função ao sinal o mais fielmente possível, e vou avaliar a qualidade do ajuste calculando a soma dos quadrados dos resíduos entre a função analítica e os dados. Quanto menor esse número, melhor o ajuste. Tudo o que precisamos informar ao Vizier é que existe essa métrica que desejamos minimizar:

metric_ssr = {
    'metric_id': 'sum_of_squared_residuals',
    'goal': 'MINIMIZE',
}

Juntando tudo isso, definimos o nosso problema:

study = {
    'display_name': 'vizier_experiment',
    'study_spec' :
    {
        'parameters': [param_model],
        'metrics': [metric_ssr]
    }
}

Observe que o Vizier não tem nenhum entendimento sobre os parâmetros em si. Gaussian e Laplace são apenas categorias de um parâmetro categórico e, para o Vizier, não têm nenhum significado além disso. Quem atribui significado a eles é o meu código que os consome — mas, para o Vizier, esse código vive dentro de uma caixa-preta. Omiti o código aqui por brevidade, mas você pode conferi-lo inteiro no link ao final do artigo para ver exatamente o que quero dizer.

Realizando a busca

Em cada teste (trial), o Vizier sugere um conjunto de parâmetros para experimentarmos. Nós mesmos avaliamos quão bem esses parâmetros funcionam, calculamos a métrica (a soma dos quadrados dos resíduos) e devolvemos o resultado ao Vizier. Ele usa esse retorno para gerar o próximo conjunto de parâmetros a testar.

O Vizier sugerindo parâmetros para os testes.

Note que o Vizier só sugere parâmetros gaussianos quando o modelo é gaussiano, e o mesmo vale para o modelo de Laplace.

Como o Vizier busca os parâmetros ótimos? Ele pode fazer busca em grade (grid search) ou busca aleatória, mas a verdadeira mágica está na combinação de outros algoritmos que ele emprega: bandits baseados em processos gaussianos, busca por combinação linear ou variações desses métodos.

Ajuste otimizado

Podemos ver que a distribuição de Laplace leva uma leve vantagem sobre a gaussiana:

Gráfico paralelo com zoom nos melhores testes que minimizam a soma dos quadrados dos resíduos. Um ajuste melhor é encontrado com a distribuição de Laplace do que com a distribuição gaussiana.

Consultamos o Vizier para obter os parâmetros do teste ótimo e os plotamos:

Parâmetros otimizados que se ajustam ao sinal ruidoso.

É um ajuste quase perfeito! Os parâmetros encontrados pelo Vizier ficaram bem próximos dos que usei para gerar o sinal antes de adicionar ruído: uma distribuição de Laplace com \(a=5\) e \(b=2\).

Sinal original de Laplace.

Para comparação, uma gaussiana teria um pico mais arredondado e caudas mais finas.

Uma distribuição gaussiana para comparação.
